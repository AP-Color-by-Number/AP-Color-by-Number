# Color by Number Setup Guide

## Required software

- A web browser.
- [Archipelago](https://github.com/ArchipelagoMW/Archipelago/releases) 0.6.7 or newer, to generate.

## Generating

Download `colorbynumber.apworld` from the [releases page](https://github.com/lighting8282/AP-Color-by-Number/releases/latest), put it in Archipelago's `custom_worlds` folder, then
generate an options file from the Launcher ("Generate Template Options").

## Playing

1. Open the client page: https://lighting8282.github.io/AP-Color-by-Number/
2. Enter the server address (for example `archipelago.gg:38281`), your slot
   name and the password, and connect.
3. Optionally upload your own image for any picture before you paint it.

Progress is saved on the Archipelago server, so you can continue on another
device. The hosted page uses HTTPS and can only reach `wss://` servers; for a
local `ws://` server, open the page over plain `http://`.
